# Archivo

Bundled locally from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/archivo).
Downloaded September 12, 2026. `Archivo.ttf` is the unmodified variable font
`Archivo[wdth,wght].ttf`; its SIL Open Font License is included in `OFL.txt`.
The panel loads this file from the extension itself, with no font network request.
